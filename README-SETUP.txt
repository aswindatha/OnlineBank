============================================
  OnlineBank - Setup Instructions
============================================

REQUIREMENTS:
  - Windows 10 or later
  - Internet connection (first time only)

HOW TO START:
  1. Extract this zip folder to any location
  2. Double-click "setup.bat"
  3. Wait for setup to finish (first time: ~5 minutes)
     - It will auto-install Python and Node.js if missing
     - It will install all dependencies
  4. Your browser will open automatically to the app

NEXT TIME (already set up):
  - Just double-click "start.bat" to launch
  - No need to run setup.bat again

TO STOP:
  - Close the two command windows that opened

TROUBLESHOOTING:
  - If browser doesn't open, go to http://localhost:5173
  - If setup fails, install Python from https://www.python.org/downloads/
    and Node.js from https://nodejs.org/ then run setup.bat again
  - If port is already in use, close other applications using port 8000 or 5173
